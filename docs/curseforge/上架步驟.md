# 上架 CurseForge 步驟

## 一、你要自己做的（帳號相關）

1. 到 https://www.curseforge.com 登入（沒有帳號就註冊）。
2. 右上角頭像 →「Create a Project」（作者控制台：https://authors.curseforge.com ）。
3. 選遊戲 **World of Warcraft**，類別 **Addons**，填：
   - 名稱、摘要（Summary）、描述：複製 `HealHPS.md`／`ProfLevel.md` 裡的內容。
   - 分類：照檔案開頭寫的選。
   - 授權（License）：建議 **MIT**（別人可以自由使用、修改，要標示作者）；不想讓別人改作就選 **All Rights Reserved**。
   - 頭像：治療 HPS 用 `addon/HealHPS/Media/Logo256.png`；專業助手等 Codex 做好的 LOGO。
4. 送出後要等 CurseForge **人工審核**（通常幾小時到一兩天）。審核過後專案網址上會有**專案 ID**（Project ID，右側 About Project 欄）。

## 二、上傳檔案（兩種方式擇一）

### 方式 A：網頁上傳（最簡單）

1. 先打包：在 repo 根目錄執行 `python tools/package.py`，zip 會在 `dist/`。
2. 專案頁 →「Files」→「Upload File」，選 `dist` 裡的 zip。
3. Game Version 選 **WoW Forever** 對應的版本（介面版本 16001）。
4. Release Type 選 Release（還在測試就選 Beta），貼上更新說明，送出。

### 方式 B：指令上傳（之後更新比較快）

1. 到 https://legacy.curseforge.com/account/api-tokens 產生 API token。
2. **自己**在 PowerShell 設定（不要貼到聊天）：
   `[Environment]::SetEnvironmentVariable('CF_API_TOKEN','你的token','User')`，重開終端機。
3. 找永恆的遊戲版本 ID：`node tools/cf-upload.mjs versions forever`
4. 上傳：`node tools/cf-upload.mjs <專案ID> dist/HealHPS-0.8.6.zip <遊戲版本ID>`

## 三、每次更新

1. 改 `.toc` 的 `## Version`。
2. `python tools/package.py`
3. 網頁或指令上傳新的 zip。
