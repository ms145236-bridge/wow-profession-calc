## 一、建立專案（每個插件做一次）

1. 登入 https://authors.curseforge.com ，按「Create a Project」。
2. 遊戲選 **World of Warcraft**，類別選 **Addons**。
3. 照介紹文字檔最上面幾行填：專案名稱、摘要、分類、授權 **GPL-3.0**。
4. 描述：複製介紹檔 `---` 中間那一大段（中文介紹），最下面的 English 那段也貼上。
5. 頭像：上傳上表的 PNG。
6. 送出後等 CurseForge 人工審核，通常幾小時到一兩天。

## 二、上傳檔案

1. 專案頁 →「Files」→「Upload File」，選上表的 zip。
2. **Game Version**：找有沒有 **WoW Forever**（或版本號 1.60）可選。
   - 有：選它。
   - 沒有：先不要送出，截圖給 Claude，再決定怎麼標示。
3. Release Type：選 **Beta**（還沒在遊戲裡完整實測過）。
4. 更新說明：寫「第一版」即可。
5. 練等幫手：在「Relations」把 **Questie**、**WaypointUI** 設成「Optional Dependency」（找得到才設，找不到就跳過）。

## 三、以後更新

告訴 Claude「上傳新版到 CurseForge」，Claude 會打包新 zip；網頁上傳步驟同上。
（想改成指令自動上傳：自己到 https://legacy.curseforge.com/account/api-tokens 產生 API 金鑰，自己設成環境變數 `CF_API_TOKEN`，不要貼到聊天。之後 Claude 用 `tools/cf-upload.mjs` 上傳。）
