# 治療 HPS 計算器（魔獸世界：永恆插件）

比較治療職各技能、各階級的 HPS（每秒治療）與 HPM（每點法力治療）。網頁版：https://ms145236-bridge.github.io/wow-profession-calc/healer.html

## 安裝

1. 下載 `HealHPS.zip`，解壓縮。
2. 把 `HealHPS` 資料夾放到 `World of Warcraft\_forever_\Interface\AddOns\`。
   放好後路徑應該是 `...\Interface\AddOns\HealHPS\HealHPS.toc`。
3. 進遊戲，在角色選擇畫面左下角的「插件」確認「治療 HPS 計算器」有勾選。
   如果顯示「過期」，勾選「載入過期插件」。

## 用法

- 滑鼠移到技能圖示上（法術書或快捷列），提示框最下面多一行 HPS／HPM；同類（單補或群補）裡 HPS 或 HPM 最高的那一階會多標一行 ★。
- `/hps`：開關視窗。每個技能一組，直接列出「HPS最高」「HPM最高」是第幾階，長條是跟同類最高值比較的長度。
  - 點技能名稱（＋）展開所有階級，再點一次收起。
  - 上方切換單補／群補；「設定」裡可以選是否列入冷卻技能、群補人數。HPS＝治療量÷施法時間（瞬發算 1.5 秒，有冷卻的技能用冷卻時間）。
  - 滑鼠移到「等級 · 治療效果」那行看天賦加成；移到任一階看法力、學習等級、降級、冷卻。
  - 底部一行是同類裡整體 HPS 最高、HPM 最高的技能。
- `/hps pct 12`：手動指定治療加成 %（`/hps pct auto` 改回依天賦自動判斷）。
- `/hps desc incl|base|auto`：技能說明的數字是否已含治療效果（永恆實測已含，預設自動）。
- `/hps tip`：開關滑鼠提示。`/hps downrank`：開關降級衰減。
- `/hps debug`：在聊天視窗列出插件讀到的東西。數值看起來不對時，請把這段輸出回報。
- `/hps reset`：重設這個角色的設定。設定是每個角色分開存的。

## 從遊戲讀什麼、用資料表補什麼

| 項目 | 來源 |
|---|---|
| 學會哪些技能、到第幾階 | 遊戲（法術書） |
| 法力、施法時間（含天賦與急速）、冷卻、學習等級 | 遊戲 |
| 基礎治療量 | 遊戲（解析技能說明文字），讀不到才用資料表 |
| 治療效果 | 遊戲（`GetSpellBonusHealing`），裝備或增益改變會即時更新 |
| 治療加成 %、吸收加成 % | 遊戲天賦：治療之光（每點 4%）、精神治療、自然賜福、淨化（每點 2%）、強化真言術：盾（每點 5%） |
| 治療係數 | 只能用資料表（遊戲不會顯示） |

法術書只顯示最高階時，插件會向遊戲查詢低階技能的法術 ID；查不到的低階技能用資料表的數值，比較表的「來源」欄會標示「資料」。

降級衰減照 ForeverChanges 的規則：學會該階技能後 17 級內不打折，之後每級少 5%，學會後 37 級歸零，只扣治療效果的部分。

不含爆擊、溢補、被覆蓋的 HoT；HoT 假設完整跑完。聖光誓約的加成伺服器沒有公開，插件沒有計算。
